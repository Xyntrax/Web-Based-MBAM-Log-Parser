# Web Based MBAM Log Parser

A web based version of the **MBAM** Log Parser for parsing logs collected by **MBST**.

## Features

- Runs entirely in your browser
- Batch processing of multiple logs
- Removes unnecessary information from MBAM scan logs
- Displays basic parsing statistics
- Download parsed logs

## How It Works

1. Upload one or more **MBAM** scan logs (*JSON*) collected by MBST
2. The parser removes unnecessary indormation using an allowlist
3. Parsed logs are generated locally in your browser
